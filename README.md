# Hayeong Ryu — Personal Website

Static personal / academic homepage. Served by GitHub Pages from `index.html`.

- `index.html` — the whole site (single file, inline CSS/JS)
- `assets/img/profile.jpg` — profile photo
- `assets/pdf/hayeong_ryu_cv.pdf` — CV
- `.nojekyll` — tells GitHub Pages to serve files as-is (no Jekyll build)

Publications default to the **Selected** view; `?view=all` shows everything.
